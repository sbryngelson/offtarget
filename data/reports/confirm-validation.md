# Confirmer validation

The confirmer (tools/confirm.py, rules catalog/confirm_rules.yaml version 2) run over every AMD/Cray case with a hand verdict: 1801 cases, 1632 agree (90%), 169 disagree, of which 0 unexplained. needs_human: 173 (9%). The bug verdicts (compiler_bug, copy_mode_failure, unified_memory_failure, arch_specific) agree with each other as a group. Offline cases use the stored evidence (result files, results/expected, the fuzz campaigns, sequential elision run where it applies); live cases ran on node-1013.

Circularity note: the `triage` and `expected` hand verdicts were made with the same expected-value machinery (tools/derive/expected.py) the rules read through the expected_record collector, so their agreement shows consistency, not independent confirmation. The rules never read catalog/mode_differences.yaml (the mode and arch classes are derived from the cells).
