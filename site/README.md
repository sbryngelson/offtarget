# site/

The inputs of the static website, which has an issue list, compiler pages, a can-use query and method pages. The pages are built from committed data only, with no compiler and no GPU. `tools/site_publish.sh OUT_DIR` runs `tools/site/site_build.py`. [../docs/tooling/site.md](../docs/tooling/site.md) and [../docs/tooling/publishing.md](../docs/tooling/publishing.md) describe building and deploying. The built output is not committed.

| path | content | kind |
|---|---|---|
| `templates/base.html` | the page frame (header, navigation, script slots) that every page is formatted into | hand-written |
| `static/site.css` | the stylesheet | hand-written |
| `static/query.js`, `issues.js`, `canuse.js` | the issue list's URL state and filtering, and the can-use query page | hand-written |
| `static/toolchains.js` | the toolchains and families the site knows | generated from `catalog/toolchains.yaml` by `tools/derive/toolchains_gen.py` |
| `inputs/atoms.json.gz` | per-atom feature support, from measurements | generated by `tools/site/site_inputs.py`, committed so a clean checkout builds |
| `inputs/citations.json` | verified specification citations of the published findings | generated by the same tool |

`python3 -I tools/site/site_inputs.py` rewrites the two files in `inputs/`. The build refuses to run when they are out of date with the catalog and findings, and raises `SiteInputError`.
