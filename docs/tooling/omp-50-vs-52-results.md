- `omp.clause.linear.uval`: CCE 19/20 accept the 5.0 `linear(uval(x))`, reject the 5.2 `linear(x: uval)` (ftn-297); AFAR: `omp.declare_simd` not yet implemented at both.
- `omp.clause.linear.val`: the 5.0 program is declare simd `linear(val(x))` (5.0 allows no modifier on loop constructs), accepted by CCE 19/20/21; the 5.2 program `linear(x: val, step(1))` on parallel do is rejected by CCE 19/20 (ftn-113) and CCE 21 (ftn-1510); AFAR: declare simd not yet implemented (5.0), an ICE (5.2).
- `omp.clause.uses_allocators.traits`: CCE 19/20/21 read the 5.0 `uses_allocators(my_alloc(my_traits))` as a function reference (ftn-451, ftn-1473) and accept the 5.2 `uses_allocators(traits(my_traits): my_alloc)` (data/findings/cce-uses-allocators-traits-omp50.f90); AFAR: uses_allocators not yet implemented at both.
