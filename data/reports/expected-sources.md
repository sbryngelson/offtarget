Method, sources and the agreement rule: [docs/tooling/expected-behaviour.md](../expected-behaviour.md). A value is **trusted** only when two independent sources (elision, metamorphic, model, probe) agree and none disagrees: the fuzz model counts only together with elision or metamorphic, a catalog program's own oracle only together with elision; metamorphic and probe are one source when a compiler family (CCE 19/20/21 are one) backs both. Consensus between toolchains is listed as a hint and never counts. Disagreements are recorded, never resolved by majority. Copy-mode (HSA_XNACK=0) runs, when present, also get a verdict of their own in the verdict column ('copy mode: ...'). For a copy-independent program (its result is the same with separate host and device copies, offload.engine.expected.copy_independent) the copy-mode runs are additional runs of the same toolchains in the main verdict: each is one more metamorphic variant of its toolchain and a toolchain's two probe runs count as one probe that must hold in both modes; they never add an independent source. A copy-dependent program's main verdict uses its HSA_XNACK=1 runs only. The catalog programs also ran on Tioga's MI250X (gfx90a, HSA_XNACK=0, the gfx90a twins of the same compilers): for a copy-independent program those runs join the main verdict the same way, as runs of the same compilers (afar_g90 is afar), never as an independent source.
