# data/index/

Reference tables the catalog is built from and checked against.

| path | what it is | origin |
|---|---|---|
| `seed/omp.json`, `seed/acc.json` | the OpenMP and OpenACC directives, clauses and categories as `llvm-tblgen --dump-json` output | dumped from the LLVM sources; `offload/engine/skeleton.py` reads them to generate `catalog/omp/skeleton.yaml` and `catalog/acc/skeleton.yaml` |
| [claims/](claims/README.md) | text snapshots of the vendor documents a claim in `catalog/*/claims.yaml` is quoted from: CCE man pages and release notes, NVHPC user guides, ROCm and AFAR status pages, the OLCF Frontier guide | fetched or rendered from the vendors' documents. `catalog/vendor_claims.yaml` lists each source, URL and version, and `tools/derive/claims.py ingest` checks every quote against the snapshots |
| `corpus_index.csv` | one row per source file in the test corpora (repo, path, language, model, kind, directives used) | generated by `tools/campaigns/index_corpus.py`; the matrix runner and the corpus checks read it |
| `directive_coverage.csv` | per directive, the versions and repositories in which the corpora use it | generated by the same tool from the seed tables |

The snapshots in `claims/` and `seed/` are inputs and are not regenerated. The two CSV files are generated, and `python3 -I tools/regenerate.py --check ompvv-corpus` tells whether `corpus_index.csv` is current. [../../docs/tooling/regenerate.md](../../docs/tooling/regenerate.md) has the details.
